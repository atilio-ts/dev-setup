Plan before coding:

1. Restate the requirements in your own words
2. Identify dependencies and risks
3. Break the work into phases with concrete steps
4. Estimate complexity (low / medium / high)
5. Present the plan and WAIT for explicit confirmation before editing any file

If the user asks for changes, update the plan and wait again.
